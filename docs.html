Capabilities

PowerHA Copilot is a single conversational agent for PowerHA operations. Every capability below is available on all plans:

Monitoring and health assessment

Reports cluster state, resource-group placement, node and network-interface status, and resource utilization on request.

Troubleshooting and diagnostics

Answers natural-language questions about cluster behavior, analyzes logs, and surfaces likely root causes with suggested remediation steps.

Disaster recovery diagnostics (GRS and GLVM)

Inspects and reports on GRS and GLVM replication and disaster-recovery configuration. Diagnostic and advisory; it does not perform failover.

Cluster operations

Reports on cluster and resource-group state. Read-only by default; a resource-group move can be armed to run live under human control, as described below.

Operational safety

PowerHA Copilot is read-only by default. Write operations run in preview and report what they would do without changing the cluster. A resource-group move executes live only when a human explicitly arms that single operation; every other operation stays read-only.
